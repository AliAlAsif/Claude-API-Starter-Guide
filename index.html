Claude API Starter Guide

Set up the API, understand token costs, protect your keys and track your prepaid credit. Works for any currency and any budget.

Four concepts that explain the rest

1. Stateless API

The model remembers nothing between calls. A chat works by resending the whole history each time, so turn 10 pays again for turns 1 to 9.

2. Tokens

A token is about 4 characters or 0.75 of an English word. You pay for input and output tokens, and output costs 5× input on every current model. Non-English text often needs more tokens per word.

3. max_tokens

Caps the output only. If it is hit, the reply is cut off and stop_reason is "max_tokens". Ask for brevity in the system prompt as well.

4. Context window

Prompts can reach about 1M tokens, but every token is billed. Haiku 5.5 charges 5× more per token once a prompt passes 100K tokens.

Making credit last

  • Develop on the cheapest model and switch up only where quality demands it.
  • Set a low max_tokens and ask for short answers, since output costs 5× more.
  • Trim chat history and never resend large files every turn.
  • Use the Batch API for bulk work, and learn prompt caching once prompts get large.

API keys: use, safety and expiry

A key (starts with sk-ant-) charges your balance. Anyone holding it can spend your credit.

ItemExpires?Notes
API keyNo automatic expiry foundActive until you delete or disable it. Rotating every 90 days is a good habit, not a rule. Confirm on your Console’s API keys page.
Prepaid creditYes, after one yearSee your date in “My credit”. Per Anthropic’s terms it cannot be extended and is non-refundable.
Key with $0 balanceKey still existsCalls fail until you add credit.

Safety rules

  • Never paste a key into code, notebooks, screenshots, chats or a public repository.
  • Use one key per project or device so one can be deleted without breaking the rest.
  • Never put a key in browser or mobile-app code. Call the API from a backend.
  • In Colab, Kaggle or CI, use the built-in secrets feature.
  • Check the Spending page regularly. Exposed keys found on GitHub are reported and deactivated, but do not rely on that.
  • To rotate: create a new key, update your apps, test, then delete the old key.
If a key leaks: delete it immediately in the Console (API keys page, three-dot menu, Delete), create a new one, and review Spending for unfamiliar usage.

Credit, billing and limits

  • Expiry: prepaid credit lasts one year from issue under Anthropic’s credit terms, with no extension and no refund. Use it in time.
  • Taxes: VAT, GST or sales tax may be added at checkout depending on your country. Use “Total paid” above to include it.
  • Auto-reload: keep it off while learning, so a bug cannot silently refill your balance.
  • Rate limits: depend on your usage tier. New accounts start low and limits grow with spending.
  • Zero balance: requests fail until you add credit.
Loop warning: never call the API inside a loop without a counter or break condition.
